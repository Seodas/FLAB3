# EXPLANATION
The user inputs have been made into the program through entry of personal information such as enrollment details, personal identification number, student's name among others. These inputs are collected using GET_TEXT macro and read_line functions where they are stored at designated address. In case of calculation of the tuition, users can input additional fees of miscellaneous, ID validation and laboratory fees. The base tuition is calculated by multiplying the 11 predetermined courses with the amount of money charged per course, which is ₱1,000, thus getting ₱11,000. Then the total tuition is generated by combining the additional charges to the base tuition. This is followed by generation of payments plan that involves down payment of 40%, midterm payment of 30%, and 30% for final payment.

Macros are important in this program due to the fact that they make Assembly code to be reduced and organized. Using macro is a way of not repeating oneself many times in the Assembly language program. The use of macros such as GET_TEXT, PRINT_FIELD and PRINT_MONEY in the program enables one to write fewer codes in Assembly while still getting what he/ she needs from the program. The additional ADD_FEE macro was utilized in making the process simple for adding additional fees to the total tuition assessment. The SHOW_COURSE macro allows the program to display the predetermined courses without repeatedly writing the same printing instructions. Overall, using macros reduces code repetition, improves readability, and makes the program easier to maintain and modify in the future.
